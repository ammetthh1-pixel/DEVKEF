📄 Texte & liens

Une page web sans lien n'est qu'une île. Ce niveau t'apprend à enrichir du texte et à connecter des pages entre elles — la base du World Wide Web.

🎯 Pourquoi ce projet ?

Le "W" de HTML veut dire "HyperText" — un texte qui contient des liens vers d'autres textes. Le lien (<a>) est littéralement l'invention qui a créé le web tel qu'on le connaît.

Ce niveau te fait aussi découvrir une idée importante : en HTML, certaines balises portent un sens (important, insistance) plutôt qu'un simple style visuel. C'est ce qu'on appelle le HTML sémantique.

📚 Les notions clés
<strong> vs <b>
<strong> dit "ce texte est important" (les lecteurs d'écran pour malvoyants le lisent différemment). <b> dit juste "affiche ça en gras", sans signification particulière. On préfère <strong> quand le contenu est vraiment important.
<em> vs <i>
Même logique : <em> (emphasis) veut dire "on insiste sur ce mot en le disant", <i> est juste visuel (italique sans signification).
<a href="..."> — le lien
L'attribut href (hypertext reference) indique la destination : une autre page (portfolio.html), un site externe (https://...), ou un espace réservé (#) si la page n'existe pas encore.
Chemin relatif vs absolu
portfolio.html est un chemin relatif : "la page portfolio, dans le même dossier que moi". https://exemple.com est un chemin absolu : une adresse complète, indépendante d'où on se trouve.
🔍 Comment décomposer le problème
1
Repère les mots qui comptent
Dans ta présentation, quel mot mérite d'être mis en avant (gras) ? Lequel mérite une insistance (italique) ? Ce n'est pas au hasard — ça doit avoir du sens en le relisant.
2
Le lien vit dans une phrase
<a> s'utilise autour d'un morceau de texte à l'intérieur d'un paragraphe — pas tout seul sur sa ligne. Exemple : Regarde <a href="#">mon travail</a> ici.
3
Deux idées, deux paragraphes
Ne mets pas tout dans un seul <p> géant. Sépare tes idées : une pour te présenter, une pour orienter vers plus d'infos.
⚠️ Pièges fréquents
✗
Lien sans href
<a>clique ici</a> sans href n'est pas un vrai lien cliquable pour le navigateur.
✗
Imbriquer dans le mauvais ordre
<strong><em>texte</strong></em> — les balises se ferment dans l'ordre inverse de l'ouverture : la dernière ouverte doit être la première fermée.
✗
Tout mettre en gras
Si tout est <strong>, plus rien ne ressort vraiment. Choisis 1 ou 2 mots clés maximum.
