🐍 Listes & dictionnaires

Ton premier vrai pas vers modéliser des données du monde réel — un contact, une tâche, un produit : tout ça se représente naturellement avec des dictionnaires.

🎯 Pourquoi ce projet ?

Jusqu'ici, tes fonctions manipulaient des nombres isolés. Un vrai programme manipule des collections : une liste de contacts, une liste de produits, une liste de tâches. Le dictionnaire ({"nom": ..., "telephone": ...}) regroupe plusieurs infos liées ; la liste de dictionnaires ([{...}, {...}]) représente une collection de ces "fiches".

📚 Les notions clés
Le dictionnaire
{"nom": "Awa", "telephone": "77..."} — accès à une valeur avec contact["nom"], comme un tableau mais avec des clés-texte au lieu de positions numériques.
Modifier ou reconstruire une liste
Pour ajouter ou supprimer, tu peux modifier carnet avec .append(), .remove() ou .pop(), puis le retourner. Tu peux aussi créer une nouvelle liste avec +, une copie ou une boucle. DevKëf valide le résultat et laisse ces méthodes à ton choix.
Parcourir avec for
for contact in carnet: te donne chaque dictionnaire un par un — utile pour chercher, filtrer, ou construire une nouvelle liste sans un élément.
None
La valeur "rien" de Python. rechercherContact doit la retourner explicitement quand le nom n'existe pas — plutôt que de laisser la fonction planter ou retourner n'importe quoi.
🔎 Le comportement de la recherche

Quand tu saisis un nom dans l'interface et que tu cliques sur Chercher, DevKëf appelle rechercherContact(carnet, nom). Ta fonction doit parcourir le carnet et retourner le téléphone du contact trouvé.

Si plusieurs contacts portent le même nom
La recherche retourne le téléphone du premier contact correspondant dans la liste. Elle s'arrête dès qu'elle trouve ce premier contact.
Si le nom n'existe pas
La fonction doit retourner None. L'interface affiche alors : Aucun contact trouvé pour « nom ».
def rechercherContact(carnet, nom):
    for contact in carnet:
        if contact["nom"] == nom:
            return contact["telephone"]
    return None
⚠️ Pièges fréquents
✗
Modifier la liste sans la retourner
Tu peux utiliser .append(), .remove() ou .pop(), mais ta fonction doit toujours retourner le carnet final avec return carnet.
✗
Oublier de retourner None explicitement
Si aucun contact ne correspond dans la boucle et qu'il n'y a pas de return None à la fin, la fonction retourne None par défaut de toute façon en Python — mais mieux vaut l'écrire explicitement pour que ce soit clair en le relisant.
🗑️ Supprimer un contact

Tu peux supprimer un contact de deux façons dans l'interface : saisir son nom puis cliquer sur Supprimer, ou cliquer sur la croix de sa ligne. Les deux actions appellent supprimerContact(carnet, nom).

Le contrat de suppression
La fonction supprime uniquement le premier contact correspondant. Si le nom n'existe pas, elle retourne le carnet inchangé. Tu peux utiliser la méthode de ton choix, notamment remove(), pop(), une copie ou une nouvelle liste.
def supprimerContact(carnet, nom):
    for contact in carnet:
        if contact["nom"] == nom:
            carnet.remove(contact)
            break
    return carnet
