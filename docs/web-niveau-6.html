📄 Responsive : adapter au mobile

Plus de la moitié du trafic web mondial vient du mobile. Un site qui n'est pas pensé pour les petits écrans en perd une bonne partie sans même s'en rendre compte.

🎯 Pourquoi ce projet ?

Ce niveau referme le premier bloc de compétences CSS en les combinant : la carte (Flexbox, niveau 4) et la galerie (Grid, niveau 5) ont chacune leur mise en page "desktop". Ici, tu leur ajoutes une seconde mise en page, "mobile", qui s'active automatiquement sous une certaine largeur d'écran.

📚 Les notions clés
@media (max-width: 768px)
Une "media query" : un bloc de règles CSS qui ne s'applique que si une condition est vraie — ici, "l'écran fait 768 pixels de large ou moins". Au-delà, ces règles sont ignorées.
Redéfinir une règle existante
Dans la media query, on réécrit .profile-card avec de nouvelles valeurs (ex. flex-direction: column). La règle la plus spécifique/la plus récente dans le fichier l'emporte — pas besoin de tout réécrire, juste ce qui change.
flex-direction: column
Change l'axe principal de Flexbox : au lieu d'aligner les enfants en ligne, ils s'empilent en colonne — parfait pour un écran étroit où il n'y a pas la place d'aligner avatar + texte + bouton côte à côte.
⚠️ Pièges fréquents
✗
Media query mal placée
Si elle est écrite avant les règles de base, celles-ci peuvent la "recouvrir" selon l'ordre du fichier. Le plus sûr : la mettre à la fin du CSS.
✗
Oublier que 768px est arbitraire
Rien de magique dans ce chiffre — c'est juste un seuil courant proche de la largeur d'une tablette. On pourrait choisir 600px ou 900px selon le design.
