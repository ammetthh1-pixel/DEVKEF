🐍 Chaînes de caractères

Compter des mots, retourner un texte, détecter un palindrome — en C, chacune de ces tâches demande de gérer manuellement des tableaux de caractères. En Python, quelques méthodes suffisent.

🎯 Pourquoi ce projet ?

Le texte est partout dans la programmation : noms d'utilisateurs, messages, fichiers, contenu web. Python traite les chaînes comme des séquences, avec des méthodes toutes faites pour les tâches courantes — ce niveau en couvre trois parmi les plus utiles.

📚 Les notions clés
texte.split()
Découpe une chaîne en liste de mots, en coupant sur les espaces par défaut. "Le chat mange".split() donne ["Le", "chat", "mange"]. Le nombre de mots, c'est juste len(...) de cette liste.
texte.lower()
Retourne une version tout en minuscules. Utile pour comparer "Radar" et "radar" comme s'ils étaient identiques.
Inverser avec le slicing : texte[::-1]
Une des astuces Python les plus connues — [::-1] parcourt la chaîne à l'envers. Pratique pour comparer un mot à son inverse (test de palindrome).
max() avec une clé
Pour trouver le mot le plus long : max(mots, key=len) retourne l'élément de la liste qui a la plus grande longueur — plus court qu'une boucle manuelle avec une variable "record".
⚠️ Pièges fréquents
✗
Comparer sans harmoniser la casse
"Radar" == "radar" est False en Python — pense à mettre les deux en minuscules avant de comparer pour un palindrome insensible à la casse.
✗
Texte vide
"".split() retourne une liste vide, pas une liste avec un élément vide — compterMots("") doit donc bien donner 0, pas 1.
