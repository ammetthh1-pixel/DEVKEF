Boucles : devine le nombre

Un nombre secret entre 1 et 100, 7 tentatives. Ta fonction ne joue pas le jeu elle-même : elle répond juste pour un essai donné. C'est DevKëf qui gère la boucle de jeu.

Python Débutant ~20 min ★ 120 XP
aperçu · devine le nombre
Aperçu — dans l'éditeur, c'est ta fonction qui décide si un essai est trop grand, trop petit, gagné ou perdu.
1 Objectifs à valider
1
Essai correct
Retourne "gagné", même au dernier essai
2
Trop grand / trop petit
Les deux sens sont détectés correctement
3
Dernier essai raté
Dernier essai sans succès → "perdu"
2 Ce que tu vas apprendre
fonctions Python if / elif / else gestion d'erreurs brancher du code à une UI
💡 Avant de commencer
Tu vas comparer une boucle Python classique avec celle de DevKëf. Dans l'éditeur, ta fonction reçoit l'état actuel et retourne l'un des quatre messages attendus.
