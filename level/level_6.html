Responsive : adapter au mobile

La carte de profil (niveau 4) et la galerie (niveau 5) sont déjà stylées pour desktop. Ton travail : les adapter au mobile avec une media query. Ça referme le premier bloc de compétences CSS.

CSS Débutant ~15 min ★ 180 XP
maquette · niveau-6
Objectif visuel — bascule automatiquement sur "Mobile" ci-dessus pour voir le rendu attendu sous 768px.
1 Objectifs à valider
1
Ajouter une media query
@media (max-width: 768px) { }
2
La carte passe en colonne
Dans la media query : .profile-card { flex-direction: column; }
3
La galerie repasse en 1 colonne
Dans la media query : .gallery { grid-template-columns: 1fr; }
2 Ce que tu vas apprendre
sélecteurs CSS couleurs typographie espacement
💡 Avant de commencer
Une media query se place généralement à la fin du fichier CSS. Tout ce qu'elle contient ne s'applique que sous le seuil de largeur indiqué.
